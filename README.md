# PawMatch

A responsive cat friendship landing page built with HTML, CSS, and Bootstrap.

## About the Project

Purrfect is a beginner frontend project inspired by TinDog, redesigned to help cat owners imagine finding new feline friends for their cats.

## Technologies Used

- HTML5
- CSS3
- Bootstrap5

## Features

- Hero section
- Features section
- Testimonials
- Pricing plans
- Footer

## Learning Goals

Practice responsive web design, Bootstrap components, and Git/GitHub workflows.
